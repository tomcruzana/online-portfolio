# 🌐 My Portfolio

A terminal-style online portfolio.

## Live Site

https://thomascruzana.com

## ✨ Commands

Type `help` in the terminal to see available commands.

- `about`
- `projects`
- `contact`
- `blog`
- `resume`
- `clear`

## 💻 Tech Stack

- React
- Vite
- HackerNoon Pixel Icon Library

## 🚀 Deployment

This project builds to a static site.

```bash
npm install
npm run build
```

Upload the contents of the `dist` folder to the web host.
